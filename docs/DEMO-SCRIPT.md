# 15-minute demo script

Press `D` to show the presenter bar: 1 Binary Search, 2 Reverse Linked List, 3 Two Sum, 4 Contribute.

| Time | What to show |
| --- | --- |
| 0–2 | The problem: show a linked-list snippet and ask "what happens to the pointers?" Open AlgoWise. |
| 2–5 | **Binary Search** (`/visualize/binary-search`). Explain low, high, mid. Press `→` a few times, then Play. Point at the red discarded cells. |
| 5–8 | **Reverse Linked List** (`/problems/reverse-linked-list`). Step through one loop: nxt saved, arrow flipped (purple), prev/curr slide. Let Play finish. |
| 8–10 | **Two Sum** or **Valid Parentheses**. Show the hash map / stack making the solution obvious. |
| 10–12 | `/contribute` and `/github`. Show `good first issue`s and `algorithms/_template`. "Contributors never redesign the UI." |
| 12–14 | Sample PRs: merged, in progress, changes requested. |
| 14–15 | "The goal is the framework that lets the community build them together." Pick an algorithm. Build its visualization. Open a PR. |

Tips: use Fast speed for the second run; `Ctrl+K` searches live; the Monaco editor needs internet once, and a built-in code view takes over if it cannot load.
